# Cloud変更をPC版へ反映する手順

## 目的
スマホのCodex Cloudで作った変更を、PC起動後にローカル版へ安全に取り込む。

## Cloud側の依頼文
```
ゲーム「レミニシア」を修正してください。
作業前に現在の状態をバックアップしてください。
変更後はGitHubのmasterへ保存し、変更ファイル一覧と動作確認結果を報告してください。
GitHub Pagesへ反映するかどうかは、反映前に確認してください。
```

## PC起動後
1. GitHubのmasterにある変更ファイルとコミットを確認する。
2. PC内の原本を別名バックアップする。
3. 差分を確認してからローカル版へ反映する。
4. PC版を起動して動作確認する。
5. 問題があればローカル変更を戻し、Cloud側へ修正を依頼する。

## 注意
- PCの電源が切れている間、ローカルファイルへ直接反映することはできない。
- Cloud作業とGitHub保存はPCがオフでも可能。
- Pages公開は別操作。公開前に必ず確認する。
- 動画・音声・秘密情報・個人情報はGitHubへ追加しない。
