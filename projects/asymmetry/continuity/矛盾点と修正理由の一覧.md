# 『アシンメトリー』矛盾点と修正理由

以下のページ表記は話内番号。改訂は作者の投稿で確認できる範囲、後続の作者指定、既存漫画ネームの順に参照した。水害、十七号室、証拠の流れ、日付の補助線は漫画側の設定。後続小説の採用済み全文は未確認。

| 論点 | 修正と理由 | 仕込み → 回収 |
|---|---|---|
| 「約束は今日」と前夜の転落 | 父の連絡・面会を十九日に固定。二十日朝の「今日」は自己責任への恐れと、十年前に証言を退けられた経験から出た嘘。 | 第1話P15–20 → 第3話P4–12・P29 → 第4話P1–4・P14–16 |
| 公園で父を捜す／「何年も行ってない」 | 面談時の言葉は真実。別れたあと病院の受付に連絡し、父の伝言で指定された時計の下へ向かう。負傷した父が自力で来るとは決めつけない。 | 第1話P19–20 → 第3話P26–29 → 第4話P2–3 |
| 転落・死亡・発見・通知 | 十九日夜に転落。同夜死亡と推定する。榊原の死の判明日に有栖が告白、翌日に遺体発見、身元確認後に通知。父の死因は転落による負傷。長谷川の搬送・隠蔽は別の行為。 | 第3話P8–12・P38 → 第4話P1–10 → 第5話P8 |
| 第一事件の時刻 | 発見は二十日朝。作者投稿には死亡推定の「前日」「今日」の揺れがあるため、漫画では十九日夜の二本目の電話以降とし、早い報道で分単位まで断定しない。 | 第1話P9–11・P22 → 第2話P1–2 → 第3話P18–19 |
| 黄色い傘 | 宏美が持って出る。長谷川が公園へ残し、老人が目視。そのあと有栖が規制線の前に、会社の忘れ物らしいと思って拾う。宏美の物と気づいても父を捜した理由を聞かれるのを恐れ、提出が遅れる。初動時の写真は遺体の資料。 | 第1話P9・P25–29 → 第3話P19・P26・P36 → 第5話P13 |
| 父の白封筒と相沢の茶封筒 | Aは父から落下し、拾った宏美が出版社の郵便受けへ。写真と父の保管場所のメモ。Bは相沢から有栖へ直接。搬送表の控えと二本の音源が入る。 | 第2話P10–13・P22／第3話P10–14・P23–24 → 第4話P19–20 → 第6話P6 |
| テープと通報 | 母の声のテープは相沢が十九日より前に病室で聴かせ、持ち帰って茶封筒へ。二本目は水害直後の搬送確認。転落夜の通報録音は所轄の別資料。胎内の主観音と後年のテープ再生も別。 | 第4話P4–6・P19–20・P32–38 → 第5話P26 |
| 宏美が何を見て、相手をどう呼ぶか | 宏美は事故の手と旧棟へ向かう搬送を目撃するが、白衣の男の名と最初の電話相手の続柄は知らない。「お姉さん」を「谷村さん」へ。 | 第3話P9・P12–17 → 第5話P2・P6–8 |
| 真が宏美をどう認識したか | 宏美に手を伸ばしていたと聞いた既存描写を残す。助けようとしていた証言を真が当時は信じず切ったことを対面で回収。獄中の後悔へつなぐ。 | 第3話P15–17 → 第5話P29–30 → 第6話P13–14 |
| 少年の入院名と本名 | 作者投稿の「早見真」を入院時の別名として採用。戸籍上は谷村誠。亡くなった双子の真とは区別し、十年前の父の署名で別名の経緯を示す。P19までは今話している声の正体を先に札で出さない。 | 第2話P27–32 → 第4話P17–18 → 第5話P19–24 |
| 「滑る」と見えない階段 | 窓から上段は見えず、濡れた下段と人が落ちてくる瞬間、その後有栖が下りる姿が見える。真の言葉は下段の有栖へ向けたもの。 | 第2話P33–36 → 第4話P11–13 → 第5話P31 |
| 長谷川の年齢と母の選択 | 十五年前の長谷川は十八歳。判断に立ち会うのは当直医と相沢。Hは純が別名で少年を入院させて真実を隠したこと、Tは父が搬送の記録から残された命を消したことへの、真の非難。 | 第4話P18–24・P29–39 → 第5話P11・P22–26 |
| 公表記録と二人の命 | 公表用の新生児搬送名簿には誠のみ。相沢の控えに残留者欄、母の紙に二人の名。母は二人の生存を求め、選択を迫られて助けられる子を先にした。 | 第4話P19–20・P24–40 |
| 二本の白い花 | 七歳の有栖が十七号室に掛け、母が保管。五歳の少年が入院時に持ち、現在は真から長谷川へ。第一・第二の現場に一本ずつで、第三・第四に増やさない。 | 第1話P33–44／第2話P12／第3話P21 → 第4話P23・P40 → 第5話P12–13 |
| 相沢・三枝・榊原のつながり | 相沢は当時の助産師で録音と控えの持ち主。三枝は現場の車と当時の資料を知る警備員。榊原は搬送表の写真を残した元消防士。有栖には資料を追う理由、長谷川には証言を封じる理由がある。 | 第3話P22–36 → 第5話P3–9 |
| 連続事件の責任 | 実行は四件とも長谷川。最初の二件は真の要求が関係し、後の二件は長谷川自身が決める。父の死だけは有栖が関わった転落事故。有栖のガガガは共有された断片であり、現場到達や人格交代の証拠にしない。 | 第2話P15–20／第3話P23–38 → 第4話P7–13 → 第5話P6–15・P27・P34–35 |
| 逮捕から刑務所まで | 事件時十五歳。家庭裁判所の個別判断で検察官送致、刑事裁判と刑の確定、面会へと時間を渡す。自死の行為は描かず、有栖には理由が分からない。対話を原因としない。 | 第5話P34–36 → 第6話P5–8・P19。制度参照 [裁判所「処分の種類」](https://www.courts.go.jp/saiban/syurui/syurui_syonen/syonen_syurui/index.html) |
| 青い扉と写真 | 有栖の電話が山下の照会のきっかけ。少女の写真は失踪届用、扉は母の旧アルバム。撮影者は元受付で、母と先月話している。建物と同じ扉が現在の断片に見えた理由は次作の謎。 | 追加P33 → P34–35 |

## 出典と創作補足

- 第1話P038〜P044は作者の研究所場面への修正指示を反映。P042の公園の鑑識台を研究所内の作業台へ変更し、P038で採取品の封緘・搬送と「同日午後／警視庁科学捜査研究所」の場面転換を補った。P039・P041・P043・P044の背景も室内へ揃えた。P040はトレイだけの接写として室内にもつながる。P036〜P037は現場での採取、P039以降は研究所での外観確認とした。字幕と搬送の動作は今回の漫画演出上の補足。現場での資料採取は[警視庁の鑑識業務](https://www.keishicho.metro.tokyo.lg.jp/saiyo/type/criminal.html)、研究所の鑑定業務は[科学捜査研究所の紹介](https://www.keishicho.metro.tokyo.lg.jp/about_mpd/shokai/katsudo/science.html)を参考とした。具体的な内部配置は漫画用の構成。

- 冒頭小説はカナメ保存の「アシンメトリー_作者投稿原稿_取得範囲.txt」とその整理「アシンメトリー_原作コンテクスト.md」。時系列監査は「アシンメトリー_父親の時系列_検証.md」。
- **冒頭小説とは別の、作者の後続メッセージ**を採用。作者は「真と有栖は兄弟で命の選択をされたもう一人双子の子供がいる」、有栖は「人格は姉は一つしかない」と訂正。「山下敬吾 が犯人を捕まえる」「誠は最後刑務所で自死」「シリーズ化するために 有栖と山下のコンビで今後事件を 解決していく」と指定。母の声は後続の作画指示で、胎児が体内から聞く声と指定された。冒頭小説の取得部分を、これらの展開の本文出典には使わない。
- 日付の固定、待ち合わせメッセージ、証拠の受け渡し、入院別名の経緯、退院ではなく診察室でいったん不在であること、少年事件の手続、写真の来歴は今回の漫画版の補足。台詞を含め、小説本文からの引用とは扱わない。
- 冒頭の「約束は、今日です」は改訂後も読者に先に答えを渡さない。第3話で十九日だったことを読者に示し、第4話で有栖本人から嘘の理由を聞く。
