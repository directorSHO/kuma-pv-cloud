# 第二構成・制作手順表とFlowプロンプト（暗転明け開始・最新版）

変更点：第1構成の終わりで暗転し、第2構成は最初から紺×銀ステージの父ソロで開始。「セリフを巻く」という指示は採用せず、セリフの速度・尺は変更しません。旧Flowプロンプト.md／背景違い_Flowプロンプト.mdより本書を優先してください。

A用の正面・胸上写真は作成済み：13_父ソロ_紺銀ステージ_正面.png。内蔵画像生成で07を参照し、下記の画像制作指定に沿って顔・衣装を維持した正面構図を生成。01_父ソロ.pngは白背景なのでAには使いません。既存09はB用の横顔アップです。

対象：0:18–0:50、計32秒。旧4カット案を、寄り・引きを混ぜた8カット案に更新。
時刻は構成上の仮配置です。音源の歌詞・歌唱者を実測していないため、父母の歌唱交代や拍に合わせて編集時に境界を調整してください。口パク同期済みではありません。

## どこで何をするか

|作業|場所|方法|
|---|---|---|
|画像から短い動画を作る|Google Flow|Frames to Video／開始フレーム対応のモードで、表のPNGを開始画像に指定。各プロンプトを貼る|
|尺・モデル設定|Flowの生成画面|横16:9、8秒を選べる設定を想定。選択可能な尺・クレジットは実画面で確認。8秒以外なら必要な使用尺以上を確保|
|動画を保存|PC|A〜Hの名前で保存。元のPNGは上書きしない|
|32秒に組み立てる|Filmora|曲を先に置き、各動画の安定した部分を表の使用尺だけ切り出す|
|暗転・文字・プロフィール|Filmora|動画生成には含めず、別トラックの素材・編集効果として追加|

Flowは開始画像から動画化できます。UIと対応機能はモデルにより異なります。
公式手順：https://support.google.com/flow/answer/16353334
モデル別対応：https://support.google.com/flow/answer/16352836

## 少ないクレジットで進める順番

1. A → E：父・母の主役映像を先に確保。
2. C → G：舞台の変化と父母ツーショットを確保。
3. D → B → F → H：細かい差し込みを追加。

無料枠の付与量や消費量はここでは固定しません。各生成前に表示を確認し、残量内で数日に分けてください。最初は1本ずつ生成して顔・衣装・手足を確認。節約するならB/Fは静止画への小さなズームで代用可能ですが、まばたき等は出ません。

## 編集で加えるもの

- 第1構成→Aの境界（仮18秒）：映像だけ短く暗転。例として17.8〜18.0秒で黒へ、18.0〜18.2秒でAを表示。既存の尺内で処理し、32秒を延ばさない。境界と長さは元映像・曲に合わせて調整。音源やセリフの速度は変えず、暗転に合わせた無音も追加しない。
- Aの生成動画自体は最初から父が見える状態。Flowには黒画面・フェード・照明点灯を作らせず、暗転はFilmoraだけで加える。26秒の再暗転は削除し、B→Cは通常カット。
- C内の27.2〜28.2秒を仮目安：05_父プロフィール_透過.png。「家族愛耐久値：測定不能」。顔・手・子どもを避け、読みやすい位置へ。短ければ1.5秒に延ばす。
- E内の35.2〜36.2秒を仮目安：06_母プロフィール_透過.png。「笑顔バフ＋999」。顔を避ける。
- Eへの切替は通常カット。Hで白背景に戻し、次の構成につなぐ。全カットに暗転を入れない。
- Flow動画に音が付いたらFilmoraでミュートし、元曲だけを通す。音声プロンプトだけでは無音を保証できません。
- 歌唱の厳密な口パクはこの工程では作れません。特にアップは口の動きが合う部分を選び、不一致なら短くするか別カットへ差し替える。

## 生成後チェック

- 人数、顔、衣装色、花飾りが元画像と一致しているか。
- 手足が増えない・背景人物と融合しないか。
- 顔が暗すぎないか。真顔の子どもが勝手に大笑いしないか。
- 必要な使用尺だけ連続して安定しているか。
- 動画名はA_父紺銀ステージ.mp4等、表のIDを先頭につける。
